# C# 修飾子・キーワード集

- ### public
  - #### 概要
    どこからでもアクセスできるようにするアクセス修飾子。

  - #### 使用例
    ```csharp
    public class SocketClient
    {
    }
    ```

  - #### 使用できる場所
    - クラス
    - メソッド
    - フィールド
    - プロパティ
    - コンストラクタ

  - #### 用途
    他のクラスから利用できるようにする。

---

- ### private
  - #### 概要
    定義したクラスの中からしかアクセスできないアクセス修飾子。

  - #### 使用例
    ```csharp
    private int _port;
    ```

  - #### 使用できる場所
    - フィールド
    - メソッド
    - プロパティ
    - コンストラクタ

  - #### 用途
    クラス内部だけで使用するデータや処理を隠す。

---

- ### readonly
  - #### 概要
    値は宣言時またはコンストラクタでのみ設定でき、その後は変更できない。

  - #### 使用例
    ```csharp
    private readonly int _port;
    ```

  - #### 使用できる場所
    - 宣言時
    - コンストラクタ

  - #### 使用できない場所
    - 通常のメソッド

  - #### 用途
    一度設定した値を変更されたくない場合に使用する。

---

- ### const
  - #### 概要
    コンパイル時に値が決まり、一切変更できない定数。

  - #### 使用例
    ```csharp
    private const int DefaultPort = 5000;
    ```

  - #### 使用できる場所
    - 宣言時

  - #### 使用できない場所
    - コンストラクタ
    - メソッド

  - #### 用途
    円周率や固定ポート番号など、絶対に変わらない値を定義する。

---

- ### static
  - #### 概要
    インスタンスではなく、クラス全体で共有するメンバーを定義する。

  - #### 使用例
    ```csharp
    public static void Main()
    {
    }
    ```

  - #### 使用できる場所
    - クラス
    - フィールド
    - メソッド
    - プロパティ

  - #### 用途
    全てのオブジェクトで共通のデータや処理を扱う。

---

- ### var
  - #### 概要
    型を自動で推論して変数を宣言する。

  - #### 使用例
    ```csharp
    var number = 10;
    var text = "Hello";
    ```

  - #### 使用できる場所
    - ローカル変数

  - #### 用途
    型を書かなくてもコンパイラに判断させる。

---

- ### new
  - #### 概要
    オブジェクト（インスタンス）を生成する。

  - #### 使用例
    ```csharp
    var client = new SocketClient(ip, port);
    ```

  - #### 使用できる場所
    - オブジェクト生成時

  - #### 用途
    クラスのインスタンスを作成する。

---

- ### out
  - #### 概要
    メソッドから複数の値を返すための引数。

  - #### 使用例
    ```csharp
    int.TryParse(text, out int number);
    ```

  - #### 使用できる場所
    - メソッドの引数

  - #### 用途
    戻り値とは別に値を受け取る。

---

- ### ref
  - #### 概要
    引数を参照渡しする。

  - #### 使用例
    ```csharp
    Add(ref number);
    ```

  - #### 使用できる場所
    - メソッドの引数

  - #### 用途
    呼び出し元の変数を直接変更する。

---

- ### async
  - #### 概要
    非同期メソッドであることを示す。

  - #### 使用例
    ```csharp
    public async Task ConnectAsync()
    {
    }
    ```

  - #### 使用できる場所
    - メソッド

  - #### 用途
    時間のかかる処理を止めずに実行する。

---

- ### await
  - #### 概要
    非同期処理の完了を待つ。

  - #### 使用例
    ```csharp
    await client.ConnectAsync();
    ```

  - #### 使用できる場所
    - asyncメソッド内

  - #### 用途
    非同期処理が終わるまで待機する。

---

- ### using
  - #### 概要
    名前空間を利用したり、リソースを自動的に解放したりする。

  - #### 使用例
    ```csharp
    using System;
    ```

    ```csharp
    using (StreamReader reader = new StreamReader(path))
    {
    }
    ```

  - #### 使用できる場所
    - ファイル先頭
    - using文

  - #### 用途
    クラスを簡単に利用する、または使用後に自動でリソースを解放する。

---

- ### namespace
  - #### 概要
    クラスをグループ化するための名前空間。

  - #### 使用例
    ```csharp
    namespace SampleApp
    {
    }
    ```

  - #### 使用できる場所
    - ソースファイル

  - #### 用途
    クラス名の重複を防ぎ、整理する。

---

- ### class
  - #### 概要
    オブジェクトの設計図を定義する。

  - #### 使用例
    ```csharp
    public class SocketClient
    {
    }
    ```

  - #### 使用できる場所
    - ソースファイル
    - 名前空間内

  - #### 用途
    オブジェクトの設計を行う。

---

- ### void
  - #### 概要
    戻り値を返さないメソッドを表す。

  - #### 使用例
    ```csharp
    public void Send()
    {
    }
    ```

  - #### 使用できる場所
    - メソッド

  - #### 用途
    値を返さない処理を作成する。

---

- ### return
  - #### 概要
    メソッドを終了し、必要に応じて値を返す。

  - #### 使用例
    ```csharp
    return true;
    ```

  - #### 使用できる場所
    - メソッド内

  - #### 用途
    呼び出し元へ値を返したり、処理を終了したりする。
