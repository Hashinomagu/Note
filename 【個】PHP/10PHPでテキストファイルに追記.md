# フォームデータの保存処理（PHP）解説

HTMLのフォームから送信されたユーザー名を受け取り、`TestLog.txt` に追記して元のページへ戻る処理の解説です。

## 全体のコード

```php
<?php
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $username = trim($_POST['username'] ?? '');

    if ($username !== '') {
        $log = date('Y-m-d H:i:s') . ' - ' .$username . PHP_EOL;
        file_put_contents(__DIR__ . '/TestLog.txt', $log, FILE_APPEND | LOCK_EX);
    }
}

// 処理が終わったら元のページにリダイレクトする
header('Location: Smple.html');
exit;
```

| コード | 役割・意味 | 備考 |
| :--- | :--- | :--- |
| `<?php` | ここからPHPのプログラムが始まる合図 | **【おまじない】** 1行目に書く |
| `if ($_SERVER['REQUEST_METHOD'] === 'POST')` | フォームからPOST送信されたときだけ `{ }` 内を実行する | **【おまじない】** URL直接アクセス時の誤作動防止 |
| `$_POST['username']` | HTMLの `<input name="username">` の入力値を受け取る | フォームデータが入る専用の箱 |
| `?? ''` | データが送られてこなかった場合に空文字（`''`）にする | **【おまじない】** エラー回避の安全装置 |
| `trim(...)` | 文字列の前後にある不要なスペースや改行を削除する | 例：`" 田中 "` → `"田中"` |
| `if ($username !== '')` | ユーザー名が空文字ではない場合に `{ }` 内を実行する | スペースのみの送信などを弾く |
| `date('Y-m-d H:i:s')` | 現在の日時を取得する | 例：`2026-11-26 12:07:00` |
| `.`（ドット） | 文字列と文字列を連結する | PHP独自の文字結合記号 |
| `PHP_EOL` | 改行コードを表すキーワード | **【おまじない】** 1行ずつ改行するために必須 |
| `__DIR__` | このPHPファイルが置かれているフォルダのパス | **【おまじない】** 同じフォルダを指定する |
| `file_put_contents(...)` | 指定したファイルに文字列を書き込む命令 | 第1引数：保存先、第2引数：書き込む内容 |
| `FILE_APPEND \| LOCK_EX` | 上書きせず末尾に追記し、同時書き込みによる破損を防ぐ | **【おまじない】** ログ保存時の定番オプション |
| `header('Location: Smple.html');` | 処理完了後に指定したページへ自動移動（リダイレクト）する | ※実際のファイル名と一致させる必要あり |
| `exit;` | ここでプログラムを完全に終了する | **【おまじない】** `header` の直後に必ず書く |
